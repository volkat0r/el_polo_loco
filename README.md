# El Pollo Loco – Jump and Run

## Projektbeschreibung

Ein klassisches Jump-and-Run-Spiel im Stil von "El Pollo Loco". Ziel ist es, Gegner zu besiegen, Münzen und Flaschen zu sammeln und den Endboss zu besiegen. Das Spiel ist für Desktop und mobile Geräte (Querformat) optimiert.

## Features

- Animierter Charakter mit Idle-, Jump-, Hurt- und Sleep-Animationen
- Verschiedene Gegnertypen und Endboss
- Statusbars für Leben, Flaschen und Münzen
- Hintergrundmusik und Soundeffekte (Mute-Button)
- Responsive Design, Mobile-Touch-Buttons
- Start-, Game-Over- und Win-Screens
- Lokale Schriftarten und Favicon
- Saubere Projektstruktur mit Klassen

## Installation & Start

1. Repository clonen
2. index.html im Browser öffnen
